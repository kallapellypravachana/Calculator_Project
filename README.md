# 🧮 Python Calculator

A feature-rich command-line calculator built with Python.

## Features
- Basic operations: +, -, *, /
- Advanced: power, sqrt, modulus
- Persistent calculation history
- Input validation & error handling

## How to Run
```bash
git clone https://github.com/yourusername/python-calculator
cd python-calculator
python calculator.py
```

## Tech Stack
- Python 3.x
- File I/O for history persistence
